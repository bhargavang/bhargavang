About

Software that ships, and keeps working.

I'm Bhargav, a software developer from India who builds Java backends, web apps and APIs.

My main project, BudgetX, is a personal-finance app built as Spring Boot microservices behind an API gateway, with Kafka events, Redis rate limiting, JWT auth and a React web app. That's how I like to build: clear service boundaries, secure by default, and easy to run with Docker.

I started out building data dashboards in Tableau and Power BI, so I care about clean data as much as clean code. I also take on freelance work: websites, online stores and custom tools for small businesses.

  1. I.

    Secure by default

    Tokens checked at the gateway, inputs validated, secrets never committed.

  2. II.

    Fast on every screen

    Built mobile-first and tuned to load quickly on budget phones and slow networks.

  3. III.

    Built to hand over

    Clean, documented code and a one-command Docker setup, so the next developer isn't lost.
